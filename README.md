# Chiara Capacci — Portfolio

Portafolio de Chiara Capacci, coreógrafa y bailarina, pensado para agencias internacionales.

- Scroll horizontal con GSAP ScrollTrigger y Lenis
- Enjambre de mariposas 3D (React Three Fiber) que reacciona al scroll y al ratón
- Fotos y vídeos que se abren con una máscara de mariposa
- Inglés y español, con transición suave
- Sonido controlado desde un único botón

## Uso

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # versión de producción en dist/
```

## Editar contenido

Textos, contacto y fotos de la galería: `src/content.ts`.
Fotos y vídeos: `public/media/`.
